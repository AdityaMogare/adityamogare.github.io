Intro

Setup problems, like a shadowed binary on PATH or a misconfigured Git, eat hours and are hard to describe in a ticket. DevLite is a lightweight developer environment doctor: one command tells you what is wrong with your setup and how to fix it, in plain English.

It's deliberately small, and built around one architectural rule that makes the whole thing testable.

Problem

Environment bugs are slow to diagnose and depend on state that's hard to reproduce on another machine.

✎

Solution

Probes gather raw facts once; rules are pure functions from facts to findings, printed as text or JSON.

✦

Results

Deterministic, golden-tested output, 26 tests and 4 scripted broken environments, installable with Homebrew.

Architecture

Probes gather, rules decide

Probes collect raw data about the platform, PATH, and Git into a single Facts struct. Rules read that struct and return Finding values. Formatters turn findings into text or JSON. Only src/platform/ is allowed to touch the OS: environment, PATH resolution, and subprocesses.

Key decision

Rules never touch the OS

Keeping rules as pure functions from Facts to Finding does three things at once:

  • Rules can be tested without a broken machine: build a Facts value in the test and assert on the findings.
  • There's no ordering dependency between checks, because no rule's output feeds another rule's input.
  • Output stays deterministic, which is what makes golden tests on the text and JSON formats possible.

The repo's own README puts it plainly: "Do not blur it."

Proof

Testing broken machines without breaking one

Unit tests use a fake environment for the platform layer, and golden files pin the exact text and JSON output. An integration harness runs the binary against four scripted broken environments. After any change to the OS-facing code, the suite runs again under AddressSanitizer and UndefinedBehaviorSanitizer. CI builds and tests on every push.

ctest --test-dir build --output-on-failure     # 26 unit + golden tests
./tests/integration/run_fixtures.sh            # 4 fixture environments

Status

What's done, and what's next

v0.1 runs on macOS 11+ with the platform, PATH, and Git probes and their first rules in place. The next piece is the Python probe and its five rules, followed by the virtual-environment and repository rules.
